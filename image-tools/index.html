Advanced use of Image Tools

1
Hit exact upload limits in two passes

Resize to the target dimensions first, then compress until the file fits under the platform cap. Resizing before compressing keeps far more quality than compressing a huge image alone.

2
Crop for the platform, not the camera

Aspect ratios differ everywhere: 16:9 for thumbnails, 1:1 for avatars, 4:5 for feeds. Crop once per destination from the same source and every post looks native.

3
Batch-prepare page images

Run every image for a page through resize and compression before upload - pages load visibly faster and you avoid the oversized hero image that quietly doubles load time.

About Image Tools

Image tools cover the three jobs people need most often: resizing, converting and compressing. Resize a photo to exact dimensions for a profile picture, convert between PNG, JPG and WebP for a website, or shrink a large image so a page loads fast. All processing happens in your browser using canvas technology — files are never uploaded.

Because the work happens locally, even large photos process in seconds and private images never leave your device. The tools expose the settings that matter — dimensions, format and quality — without burying them in menus, and they preserve aspect ratio by default so nothing comes out stretched. Results download instantly with sensible file names.

  • Resize images to exact pixel dimensions for profiles and thumbnails
  • Convert between PNG, JPG and WebP formats
  • Compress photos to reduce page weight and load faster
  • Crop images to standard aspect ratios
  • Optimise images without uploading them to any server
