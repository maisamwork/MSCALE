What Is the PDF Split?

A PDF is often one big file when you need small ones. A fifty-page report contains one chapter a colleague needs. A scanned pack holds twelve documents that must be filed separately. A contract needs just the signature page for a quick confirmation. This PDF Split tool extracts exactly the pages you want into a new PDF, and like every tool on this site, it works entirely inside your browser so private documents are never uploaded.

Give it a file and a page range in plain language, such as 1-3 for the first three pages or 2,5,9-12 for a mix of single pages and ranges. The tool builds a new PDF containing only those pages, copied at full quality, and offers it as a download. Your original file stays complete and untouched.

Splitting is the counterpart of merging, and together they cover most document assembly work. Extract a chapter to share, pull an invoice out of a statement pack, save just the signed pages of an agreement, or break a bulk scan into individual documents for filing. All of it happens locally with no account and no watermark.

How to Use the PDF Split

Select a PDF, type the pages you want using commas and hyphens, then extract and download. Pages keep their original quality and order, and the source file is never modified.

  1. Click the file field and choose the PDF you want to split.
  2. Type the pages to keep, for example 1-3 or 2,5,9-12.
  3. Check the page count shown for the file to make sure your range exists.
  4. Optionally give the output file a descriptive name.
  5. Click Extract Pages and wait for the confirmation.
  6. Click Download to save the new PDF containing only your chosen pages.

How the PDF Split Works

Under the hood the tool uses pdf-lib to create an empty PDF document and copy your selected pages into it from the source file. Because pages are copied as objects, everything about them survives: selectable text, embedded fonts, links, form fields and image quality. There is no re-rendering step that could blur or flatten anything.

The range syntax is deliberately simple. Commas separate picks, and a hyphen between two numbers means every page from the first to the second inclusive. So 1,3,7-10 keeps page 1, page 3 and pages 7 through 10. The tool validates your input against the actual page count and tells you immediately if a range is impossible, instead of silently producing a wrong file.

Local processing is what makes this tool safe for confidential documents. Splitting often involves the most private pages of a document: salary slips inside a contract, medical results inside a health record, one person's details inside a batch export. Those pages are read by your browser and written into a local download, with no server involved at any point in the process.

Splitting also plays a role in file size management. A single page extracted from a large scan is usually far smaller than the whole document, which matters when an upload form enforces a strict limit or an email client chokes on attachments. Extracting only the required pages is often the fastest way to shrink a PDF without any compression step, because you simply stop carrying the pages you do not need.

Examples and Practical Use Cases

Sharing one chapter

A student needs to share chapter four of a course reader. Extracting pages 61 to 84 creates a small, focused PDF that is easy to email instead of the entire two-hundred-page book.

Filing scanned documents

A single scan contains a utility bill, an insurance letter and a bank statement. Splitting it into three files, one per document, produces properly named records for a filing system.

Sending just the signature page

A counterparty asks for proof of signature only. Extracting the signed page from a twenty-page agreement shares exactly what was asked, and nothing more.

Common Mistakes to Avoid

  • Typing ranges beyond the actual page count, which the tool rejects; check the page count shown before extracting.
  • Confusing page labels with page positions, since a PDF printed as 1, 2, 3 may internally start at a different position; the tool counts from the first physical page.
  • Expecting the original file to change; splitting creates a new download and never edits the source PDF.
  • Entering ranges with spaces or plus signs instead of the supported comma and hyphen syntax.
  • Deleting the original after splitting, only to discover you needed a page you did not extract; keep the source until you are sure.

Tips, Benefits and Limitations

  • Use single pages and ranges together, like 1,4-6,11, for precise extraction.
  • Name outputs after their content, such as chapter-4.pdf, rather than keeping generic split names.
  • To break a PDF into individual pages, run the tool once per page; for large jobs, merge the singles later in the order needed.
  • Extract the pages you share with others, rather than sending a whole document and asking them to find page nine.
  • Combine with the PDF Merge tool: split out what you need from several files, then merge the extracts into one clean document.
  • Remember the tool is free and unlimited, so experimenting with ranges costs nothing.

Frequently Asked Questions

Are my files uploaded anywhere?

No. Splitting happens entirely in your browser using pdf-lib. The file is read locally, the new PDF is built in memory and delivered as a download, with no server involved.

How do I pick non-consecutive pages?

Separate picks with commas and use hyphens for ranges. For example, 1,3,7-10 keeps page 1, page 3 and pages 7 to 10 inclusive.

Does the extracted PDF keep text and links?

Yes. Pages are copied as original objects, so selectable text, fonts, images, links and form fields all carry over at full quality.

Can I split a password-protected PDF?

No. Encrypted files cannot be read without their password, so the tool cannot process them. Remove protection in the originating application first if you are authorised to do so.

Will the original file be modified?

Never. The tool reads the source and writes a separate new file; your original PDF stays exactly as it is.

Is there a page limit or watermark?

No. The tool is free, unlimited and adds nothing to your documents. The only practical limit is your device's memory for very large files.
